MARTIAN MAP — Marswalk Planner (NASA Space Apps Challenge 2026 · Interplanetary Survival Guide: Martian Map · Team PERIAPSIS)

RUN
  Windows     : double-click Start-Windows.bat
  macOS/Linux : in a terminal, ./start-mac-linux.sh
  Your browser opens http://127.0.0.1:8765/ by itself.
  Needs: Python 3 (no extra packages) and a recent browser (Chrome / Edge / Firefox).
  Note: double-clicking app/index.html does NOT work (browser security rules).
  Close the black window to stop the app.

QUICK TOUR
  1. Mission setup     - suit, carried equipment and the pressurized rover
  2. PLAN SCIENCE EVA  - picks the best geology / mineral stops that fit the 8 h EVA budget
  3. Ground view       - see each stop through the rover's own cameras
  4. Route & EVA       - choose SAFE / ECO / FAST / AUTO, read the GO / NO-GO card
  5. START EVA         - the two-person crew walks the plan (x1 ... x600, ABORT EVA)
  6. Map Layers        - DRAPE ON 3D TERRAIN: minerals, thermal inertia, rocks, geology, slope
